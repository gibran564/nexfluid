La cola M/M/1

Llegadas de Poisson con tasa λ, un servidor con tiempos de servicio exponenciales de tasa μ y capacidad ilimitada. El sistema es estable si ρ = λ / μ < 1.

Fórmulas

L = ρ / (1 − ρ)
Wq = λ / (μ (μ − λ))
W = 1 / (μ − λ)

La ley de Little relaciona las tres: L = λ · W.
