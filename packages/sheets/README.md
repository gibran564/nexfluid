# @eclipsis/sheets

NexSheets Core: modelo de hojas de cálculo sin framework ni estilos (libros, celdas, rangos, selección, historial, fórmulas, autollenado, CSV/TSV/JSON y ejes para virtualizar). El editor para React está en `@eclipsis/react/sheets`.

Fórmulas: intérprete propio y cerrado (sin `eval`), funciones en español e inglés (`FORMULA_NAMES`). Sin referencias entre hojas, matrices ni fechas; no es compatible con Excel al completo.

Parte de **NexFluidUI · Living Editorial Interfaces**. Documentación: https://gibran564.github.io/nexfluid/
